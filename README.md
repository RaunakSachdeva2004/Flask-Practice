# Flask Practice

A hands-on repository for learning and building web applications and REST APIs with **Flask**, created as part of the MLOps Bootcamp curriculum.

---

## 📌 Overview

This project serves as a structured practice ground for exploring core Flask concepts, building scalable backend services, and preparing web services for machine learning model deployment and MLOps pipelines.

---

## 🚀 Features & Roadmap

- [x] Basic WSGI application setup & routing (`/`)
- [x] Dynamic routing & URL parameters
- [x] Jinja2 templating & HTML rendering
- [x] Handling GET & POST requests and form data
- [x] Building RESTful APIs with JSON responses
- [x] Error handling & custom HTTP status codes
- [x] Integration with ML inference pipelines

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Framework:** [Flask](https://flask.palletsprojects.com/)
- **Architecture:** WSGI (Web Server Gateway Interface)

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/RaunakSachdeva2004/Flask-Practice.git
cd Flask-Practice
```

### 2. Create and Activate a Virtual Environment

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install flask
```

### 4. Run the Application

```bash
python app.py
```

The application will start locally. Open your browser and navigate to:
```
http://127.0.0.1:5000/
```
